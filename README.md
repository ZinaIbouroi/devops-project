# DevOps Project 🚀

## 📌 Description
This project demonstrates a simple DevOps pipeline:
- A Flask application
- Docker containerization
- CI/CD pipeline with GitHub Actions

## ⚙️ Tech Stack
- Python (Flask)
- Docker
- GitHub Actions

## 🚀 How to run locally

```bash
docker build -t devops-app .
docker run -p 5000:5000 devops-app
